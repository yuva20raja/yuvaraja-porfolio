FEATURED FINAL SEMESTER CAPSTONE PROJECT

Secure Peer-to-Peer File Transfer: Zero-Trust Decentralized Sharing

Built as a comprehensive final semester engineering capstone at Karunya Institute of Technology. A desktop application enabling secure, serverless file sharing across decentralized nodes using end-to-end encryption, secure key exchange, and hashing-based integrity verification without relying on central storage.

The Challenge

Eliminating single-point-of-failure vulnerabilities, central storage data leaks, and third-party sniffing during sensitive data transmission.

The Architecture

Engineered in Python using socket-level stream chunking, hybrid AES-256 GCM encryption, RSA key exchange, and multi-threaded transfer pipelines.

Reliability & Resumability

Implemented resumable transfers, real-time progress tracking, automatic file expiry, and cost-effective serverless peer communication.

Cryptographic Integrity

100% cryptographic integrity guaranteed via SHA-256 checksums calculated and verified at both peer endpoints before decrypting.
